03 · the paint tin

Nearest — measured like eyes

brand navy · 030C1E
pure black · 000000
RGB says: every number differs (3, 12, 30).
Your eyes say: nearly identical.
RGB distance lies — so the engine doesn’t use it.
CIE Lab — a color space built so distance matches perception
ΔE 12.6 — a subtle difference · ΔE76 = straight-line distance in Lab
for scale — the demo deck’s real remaps measured ΔE 20.6 – 63.0: clearly different colors. The mapping picks the smallest ΔE to a brand color; ties break by hue.
RGB Color as red/green/blue numbers. Storage-friendly — but distances don’t match what eyes see.
CIE Lab A perceptual color space: L is lightness, a and b the color axes. Equal steps look equal.
Delta-E (dE76) One number for “how different do these look?” — straight-line distance in Lab, implemented by hand.
perceptual color distance Measuring like eyes, not like storage. It’s the difference between designed and spreadsheet.
04 · Lab space

Role-preserving mapping

red text C00000 → brand danger E5484D · ΔE 26.4 TEXT stays TEXT
dark fill 1F4E79 → brand background 030C1E · ΔE 33.4 BACKGROUND
chart line 2E75B6 → brand accent 00E5FF · ΔE 53.5 DATA INK
classify the role first — lightness, saturation, context — then map to the brand color playing the same role. Near-white on a dark slide is text; the same hex in a chart bar is data ink.
every decision lands in the change log — with its role and its ΔE
role-preserving mapping Map a color to the brand color playing the same role. Red text stays text — never a background.
role classification The guess that makes mapping safe: background, surface, text, accent — from luminance + context.
hue affinity Ties broken by hue: warm stays warm. Red never becomes cyan “because numbers”.
change log One row per edit: before → after, role, ΔE, confidence.
